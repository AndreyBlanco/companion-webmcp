# Adaptive semantic memory experiment

The isolated experiment established that natural text can produce an additive, source-linked semantic delta while retaining the exact confirmed `rawText`. It also demonstrated active-subject continuity, explicit ambiguity, provenance preservation, subject-first filtering, positive evidence selection, and an honest negative result.

The promotion deliberately retained only the small domain-neutral memory engine and WebMCP contract. Provider probes, model traces, temporary JSON, external-agent harnesses, and experiment servers were not promoted. The public demo adapter uses a deterministic, independently invented Hyundai scenario so the repository is reproducible without a paid provider or laboratory artifact.

Known limitation: evidence selection is record-level. A selected record can include secondary semantic items that are not strictly necessary for the question. Block 1 intentionally does not change that projection behavior.
